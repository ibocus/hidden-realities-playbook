# Hidden Realities Playbook — Project Setup

## PHASE 1: CROSS-DEVICE SETUP (Do This First)

### Step 1: Upload Capture Workbook to Cloud
1. Download `Playbook_Story_Capture.xlsx` to your laptop
2. Upload it to **Google Drive** or **OneDrive** (pick one):
   - **Google Drive**: New folder → "Hidden Realities Playbook" → upload file
   - **OneDrive**: Same approach
3. Share the folder (or file) as "Editor" access so you can edit on any device
4. **Result**: Workbook syncs automatically across laptop and Mac

### Step 2: Access in Claude on Any Device
- **On your laptop**: Open Claude (web or app), upload the workbook → I can read it
- **On your Mac**: Open Claude, upload the same workbook → I read the latest version
- **Alternative**: Link to the file in messages (e.g., "Check my latest captures in [Google Drive link]")

### Step 3: Add to Your Workflow
- **Laptop**: After workshops, dump raw notes into the workbook (date, phase, theme, raw notes)
- **Mac**: Add lessons/takeaways when you have time to reflect
- **Either**: Upload periodically to Claude for synthesis (monthly)

## PHASE 2: QUICK CAPTURE WORKFLOW

### When a Hidden Reality Emerges:
1. **Date**: Today's date (YYYY-MM-DD)
2. **Project Phase**: Pick from:
   - Assessment & Discovery
   - Design & Documentation
   - Implementation & Evidence
   - Audit & Readiness

3. **Theme**: Pick from the Theme Tracker sheet (or create new one)
4. **Story Title**: One-line headline of the discovery
5. **Raw Notes**: Dump everything (don't worry about polish)
6. **Hidden Reality**: State the assumption vs. the actual reality
7. **Decision Made**: What did you choose to do about it?
8. **Lesson / Takeaway**: What would you tell someone else?
9. **Time Investment**: Hours spent on this task
10. **Status**: Leave as "Raw" — we'll move to "Drafted" → "Ready" later

**Time to capture**: 5–10 minutes per story. Keep it rough.

---

## PHASE 3: MONTHLY SYNTHESIS

**On the last Friday of each month:**
1. Upload the workbook to Claude
2. I read all new stories (raw) since last month
3. I identify:
   - Patterns across stories
   - Which themes are well-covered, which need more
   - Strongest stories (most instructive)
4. I draft **2–3 short insights** for LinkedIn teaser posts
5. You edit, post to LinkedIn
6. We mark those stories "Drafted"

---

## PHASE 4: QUARTERLY DEEP DIVE

**Every 3 months:**
1. Upload workbook + any new materials
2. I help you:
   - Outline which themes will be chapters
   - Identify the strongest stories per chapter
   - Spot gaps (which themes need more coverage?)
3. Begin drafting chapter narratives

## Tips for Success

1. **Capture early**: Do it while the memory is fresh, within 24 hours of the discovery
2. **Be honest**: The rougher/more real, the better. This is for you first, audience second.
3. **Cross-link**: If one story relates to another, note it
4. **Time tracking**: Logging time helps you spot where the real effort goes
5. **Review monthly**: Seeing patterns emerge is motivating
